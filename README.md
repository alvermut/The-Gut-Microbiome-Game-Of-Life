# Gut Microbiome Game of Life

A browser simulation of microbes growing in a circular gut environment. Choose the Bacteria or Conway rule, adjust the settings, and see how the population changes.

## Run

Requires Python 3, Pillow, and npm.

```sh
python3 -m pip install -r requirements.txt
npm start
```

Open http://localhost:8000.

## Play

Enter a name and press **START**. Use the antibiotic, probiotic, and leaky gut controls during the run. Press **SEQUENCE YOUR GUT MICROBIOME** to end the run and see the relative abundance of each microbe function.
